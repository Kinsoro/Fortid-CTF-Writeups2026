# Reverse Engineering

Writeups for reverse-engineering challenges involving executable analysis, program logic, or obfuscation.

## Challenges

Create a separate directory for each challenge. Include the tools used, the key observations, the analysis process, and a reproducible solution where permitted.

## Suggested writeup sections

- Challenge overview and file identification
- Static and/or dynamic analysis
- Important functions, strings, or control flow
- Solution logic and verification
- Lessons learned
