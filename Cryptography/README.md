# Cryptography

Writeups for cryptography challenges, including classical ciphers, encoding mistakes, weak implementations, and protocol puzzles.

## Challenges

Create one directory per challenge and explain the cryptographic reasoning clearly. Distinguish encoding from encryption, state assumptions explicitly, and verify the recovered plaintext or flag.

## Suggested writeup sections

- Challenge overview and given artifacts
- Cryptographic primitive or construction
- Weakness or mathematical observation
- Solution steps and supporting code
- Verification and lessons learned
