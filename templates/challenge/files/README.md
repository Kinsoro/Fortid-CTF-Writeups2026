# Challenge Files

Place the original files supplied with this challenge in this directory, preserving their filenames where practical.

Examples include:
- Challenge archives (`.zip`, `.tar.gz`, and similar)
- Source code and project files
- Executables and other binaries
- Configuration files, data files, and documents

Do not place scripts or payloads created during your solution here unless they were included in the original challenge package. Keep generated artifacts in an appropriately named directory outside `files/`.

If the challenge provided no downloadable files, replace this template with a short note stating: `No challenge-provided files were supplied.`

Before publishing, verify that the competition rules permit sharing every included artifact.
